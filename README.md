# Realistic Profile Pictures

An agent skill that generates realistic, natural-looking AI profile pictures and avatars that **do not look AI-generated**. For filling app mockups, website avatars and testimonial pages, marketing, demos, prototypes, and video with believable, diverse people, instead of uncanny AI output or the same recycled stock photos everyone uses.

![Realistic AI profile pictures generated by this skill](assets/preview.png)

Packaged from [realpfp.vercel.app](https://realpfp.vercel.app) (source: [heyimjames/RealPFP](https://github.com/heyimjames/RealPFP)).

## Install

Works with Claude Code, Cursor, and any agent that supports the [skills](https://www.npmjs.com/package/skills) format:

```bash
npx skills add heyimjames/realistic-profile-pictures
```

Once installed, just ask your agent for "realistic profile pictures", "avatars for a mockup", or "placeholder faces" and it runs the skill.

## Use it directly

Requires Node 18+ and a free [fal.ai key](https://fal.ai/dashboard/keys) (bring your own).

```bash
# preview the prompts only, no API calls, no cost
node scripts/generate.mjs --count 3 --mode profile --dry-run

# generate images
FAL_KEY=your_key node scripts/generate.mjs --count 6 --mode profile --out ./faces
```

Flags: `--count` (1 to 50), `--mode aspirational|profile|candid`, `--out`, `--aspect`, `--resolution 1K|2K`, `--dry-run`. Images save as `pfp-01.png`, `pfp-02.png`, and generation runs four at a time to respect fal.ai rate limits.

## What makes the faces look real

The value is the prompt engine, not the API call. nano-banana-2 is a Gemini-family model, so the engine leans on a few ideas:

- **Positive description beats negation.** It describes what a real photo actually has (visible pores, one light source, a single catchlight, correct anatomy) rather than naming what to avoid. Naming "plastic skin" to forbid it can summon it.
- **No poison words** (flawless, perfect, radiant, stunning, 8k) that trigger the plastic beauty-filter look.
- **An anatomy clause** with a "hide the hand rather than mangle it" fallback for tricky poses.
- **Three looks:** `aspirational` (polished but real), `profile` (natural, postable), `candid` (documentary).
- **Diverse subjects and coherent scenes**, where weather, light, and time of day always agree.

Full write-up: [reference/prompt-principles.md](reference/prompt-principles.md).

## Notes

- Bring your own fal.ai key. It is only read from the environment for the API call and is never stored.
- Curate the output. Image models still slip on complex hand poses occasionally, so generate a few extra and keep the best.
- This generates fictional people for design and marketing use. It is not for impersonation or headshots of a real person.
